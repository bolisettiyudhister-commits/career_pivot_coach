# PivotPath — Career Pivot Coach

A small full-stack career planning website built with:
- **HTML** — page structure
- **CSS** — responsive styling
- **JavaScript** — interactive skill analysis, interview practice, and progress UI
- **Python (Flask)** — backend API and local progress storage

## Run locally

1. Install Python 3.10 or newer.
2. Open a terminal in this project folder.
3. Create and activate a virtual environment (optional but recommended).
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the server:

   ```bash
   python app.py
   ```

6. Open http://127.0.0.1:5000 in your browser.

## Included features

- Resume/background and target-role intake
- Keyword-based skill-gap map from a pasted job description
- Four-week learning roadmap generated by the Python API
- Portfolio project suggestions
- Mock interview practice with a simple rubric-based review
- Application tracker and response-pattern summary
- Progress checklist saved locally in `progress.json`
- Export progress as JSON

## Note

This is a learning-project prototype. The job-description analyzer uses common keyword matching, the interview score is a practice heuristic, and the app does not connect to live job boards or an external AI model.
